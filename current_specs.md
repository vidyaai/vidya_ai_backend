- Instructors can create courses,
- Instructors can enroll students in courses,
- Instructors can manage course materials
    - Lecture notes
    - Lecture videos
- Students can "Chat with course materials"
- Instructors can manage Question Sets
    - Create Question Sets
        - Auto create Question Sets (auto-generate grading rubrics and correct answers)
            - from lecture notes
            - from lecture videos
            - by writing a prompt
            - or any combination of the above
            * set total marks for the Question Set
            * control the
                * difficulty of the Question Set
                * difficulty distibution of questions
                * marks and difficulty distribution of questions
            * control the question types (multiple choice, short answer, numerical, diagram, etc.)
            $ having questions with or without diagrams
                $ diagram updatable with prompts
        - Parse Question Sets (auto-generate and/or parse grading rubrics and correct answers)
            - from pdf files
        - Manually create Question Sets
    - Publish Question Sets to enrolled students
        - students can upload Solution in pdf format
        - students can submit Solution in-app using the UI
    - Download Question Sets in pdf format
        - students' copy (without answers and rubrics)
        - instructor's copy (with answers and rubrics)
    - Auto-grade the submitted Solution
        - based on grading rubrics and correct answers
        - provide feedback (visible to students and instructors)
- Instructors gets the Class Performance
    - Pick Question Sets and assign weightages to analyze and export class-wide performance
    - Weighted total — class distribution
    - Submission & on-time rate per assignment
    - Class average over time (by due date)
    - Per-assignment score distribution
    - Per-student leaderboard

- Students/Instructors can "Chat with a Video"
    - they ask questions about specific parts/frames of the video and receive answers based on the content of the video.
    - they can take a quiz on the video content and receive feedback on their performance.
    - generate and download summary of the video content
